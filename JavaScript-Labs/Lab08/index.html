JavaScript-Labs / Lab 08

Lab 08 Language Foundations

11 Exercise làm quen với JavaScript: cách đưa script vào trang, dùng Console, các đối tượng có sẵn, mảng, hàm và đối tượng. Bấm vào từng ô để mở bài chạy thực tế.

  • 8.1

    Enabling/Disabling JavaScript

    Trang tự kiểm tra trình duyệt đang bật hay tắt JavaScript: khi bật thì script ghi ra dòng “You have JavaScript enabled”, khi tắt thì thẻ <noscript> hiện dòng “You have JavaScript disabled”.

    Mã nguồn: exercise01.html
  • 8.2

    Embedded JavaScript

    Nhúng một đoạn script trong thẻ <head> để hiện hộp thoại alert("Hello World!") trước khi trang hiển thị.

    Mã nguồn: exercise02.html
  • 8.3

    External JavaScript

    Tách code ra file hello.js và nạp bằng thuộc tính src. File này dùng document.write để in dòng chữ và giá trị biến count lên đầu trang.

    Mã nguồn: exercise03.html, hello.js
  • 8.4

    Using NoScript

    Thêm thẻ <noscript> để hiển thị thông báo thay thế cho người dùng đã tắt JavaScript.

    Mã nguồn: exercise04.html, hello.js
  • 8.5

    Using the Browser Console

    Chuyển hello.js vào thư mục js/, cố tình viết sai document thành doccumment để đọc lỗi trong Console, sửa lỗi, rồi dùng Console để xem biến count, output, temp và ghi thông báo bằng console.log, console.warn, console.error.

    Mã nguồn: exercise05.html, js/hello.js
  • 8.6

    Using Built-in JavaScript Objects

    So sánh chuỗi tạo bằng new String() với chuỗi viết trực tiếp qua typeof, == và ===; in ngày giờ hiện tại bằng Date và thử Math.PI, Math.sqrt, Math.random.

    Mã nguồn: exercise06.html, js/exercise06.js
  • 8.7

    Arrays

    Tạo mảng các ngày trong tuần, thêm Sat bằng push() và Sun bằng unshift(), rồi dùng vòng lặp và điều kiện để vẽ bảng lịch 30 ngày bắt đầu từ Chủ nhật; Tues và Thur được in nghiêng màu đỏ.

    Mã nguồn: exercise07.html, js/exercise07.js
  • 8.8

    JavaScript Functions

    Viết hàm outputBox() qua ba bước: tự in ra trang, trả về chuỗi, rồi nhận tham số num; gọi hàm trong vòng lặp để tạo 5 ô div. Thử phạm vi biến: biến khai báo bằng var trong hàm không dùng được bên ngoài, bỏ var thì thành biến toàn cục.

    Mã nguồn: exercise08.html, js/exercise08.js
  • 8.9

    Functions as Objects

    Tính tổng tiền giỏ hàng có thuế 5%. Hàm tính thuế suất lần lượt được viết thành hàm lồng nhau, hàm gán cho biến, hàm ẩn danh và cuối cùng là hàm truyền làm tham số cho calculateTax().

    Mã nguồn: exercise09.html, js/exercise09.js
  • 8.10

    Creating JavaScript Objects

    Tạo đối tượng đơn hàng theo bốn cách: new Object(), ngoặc vuông, object literal và hàm khởi tạo. Bản cuối dùng hàm khởi tạo order() có phương thức total() và output() để in hai đơn hàng.

    Mã nguồn: exercise10.html, js/exercise10.js
  • 8.11

    Arrays of Objects

    Duyệt mảng các đối tượng Country, truy cập thuộc tính bằng dấu chấm và ngoặc vuông, rồi dùng for..in để in mọi thuộc tính của từng quốc gia kèm hình lá cờ.

    Mã nguồn: exercise11.html, js/exercise11.js
