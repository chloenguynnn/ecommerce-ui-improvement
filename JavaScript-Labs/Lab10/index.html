Lab 10 jQuery

10 Exercise với thư viện jQuery: nạp thư viện, bộ chọn, sự kiện, chèn phần tử, hiệu ứng, GET request và jqXHR. Bấm vào từng ô để mở bài chạy thực tế.

  • 10.1

    Set Up jQuery

    Nạp jQuery 3.1.1 từ CDN qua HTTPS và thêm đoạn dự phòng tự nạp bản js/jquery-3.1.1.min.js trong repository nếu CDN không tải được. Trang in ra phiên bản jQuery để xác nhận.

    Mã nguồn: exercise01.html, js/exercise01.js, js/jquery-3.1.1.min.js
  • 10.2

    Basic Selectors

    Dùng hàm $() với bộ chọn id, thẻ và class; thử val(), html(), attr(), css() và addClass(). Một lệnh áp dụng cho cả tập phần tử mà không cần vòng lặp.

    Mã nguồn: exercise02.html, js/exercise02.js
  • 10.3

    Advanced Selectors

    Dùng bộ chọn nâng cao :password, :nth-child(4n) và :contains("word") để tô màu các phần tử trong form Registration.

    Mã nguồn: exercise03.html, js/exercise03.js
  • 10.4

    jQuery Listeners

    Gắn nối tiếp ba sự kiện cho ô .panel bằng on(): mousemove báo tọa độ chuột, mouseleave báo “goodbye!”, click gỡ sự kiện mousemove bằng off(). Code đặt trong $(function(){...}).

    Mã nguồn: exercise04.html, js/exercise04.js
  • 10.5

    Inserting DOM Elements

    Tạo thẻ <img> bằng jQuery và chèn vào trang theo các cách after, before, append, prepend, appendTo, prependTo, insertBefore để thấy vị trí khác nhau.

    Mã nguồn: exercise05.html, js/exercise05.js
  • 10.6

    Simple jQuery Animation

    Sáu nút điều khiển ảnh bằng fadeIn, fadeOut, fadeToggle, slideDown, slideUp, slideToggle.

    Mã nguồn: exercise06.html, js/exercise06.js
  • 10.7

    More jQuery Animation

    Rê chuột lên ảnh nhỏ thì ảnh chuyển xám và một khung xem trước chứa ảnh lớn kèm chú thích hiện dần ra, đi theo con trỏ; rời chuột thì khung bị xóa.

    Mã nguồn: exercise07.html, js/exercise07.js
  • 10.8

    Complex Animations

    Dùng animate() để đổi cùng lúc left, opacity, height của hộp, rồi nối tiếp thêm hai chuyển động chạy lần lượt.

    Mã nguồn: exercise08.html, js/exercise08.js
  • 10.9

    GET Requests

    Bấm Consume để gửi GET request bất đồng bộ bằng $.get(), nhận danh sách thành phố dạng JSON rồi dùng $.each() tạo từng thẻ <li>. Dịch vụ mẫu của giáo trình chỉ chạy HTTP nên bị chặn trên GitHub Pages (HTTPS); bài dùng file data/cities.json cùng cấu trúc.

    Mã nguồn: exercise09.html, js/exercise09.js, data/cities.json
  • 10.10

    jqXHR Handling

    Dùng đối tượng jqXHR mà $.get() trả về: done() đổ dữ liệu vào danh sách, fail() báo lỗi, always() ẩn ảnh đang tải. Nút “Consume (wrong URL)” gọi một địa chỉ không tồn tại để thử nhánh fail().

    Mã nguồn: exercise10.html, js/exercise10.js, data/cities.json
